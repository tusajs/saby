# Приёмка онлайн-записи ÉLAIRE

[Скачать отчёт в HTML](https://raw.githubusercontent.com/tusajs/saby/main/testing-4/report.html). Сохраните файл и откройте в браузере. Отчёт автономный, таблицы и цветовая разметка работают без подключения к сети.

В отчёте собраны карта функций, матрица требований, тесты, результаты прогона и два баг-репорта. Из 14 проверок прошли 10. Четыре выявили нарушения валидации телефона и имени.
