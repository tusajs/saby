Карта функций

  • Каталог → выбор категории → обновление списка → карточка → описание, цена, длительность → выбор услуги.
  • Календарь → навигация по месяцам → выбор даты → определение доступности интервала → выбор времени → обновление сводки → переход к форме.
  • Контакты → заполнение имени и телефона → проверка длины, алфавита, маски и обязательности → ввод необязательного комментария.
  • Подтверждение → сверка деталей визита → отправка → окно результата → проверка услуги, цены, мастера и времени.

Вход в тестирование

  1. Открывается главная.
  2. Из главной доступен каталог.
  3. Категория маникюра содержит карточку P.Shine.
  4. Выбор услуги открывает календарь.
  5. Свободный интервал выбирается и открывается форма контактов.
  6. Попытка отправки формы даёт наблюдаемый результат.

Все шесть smoke-проверок пройдены. Этого достаточно для начала полного прогона.

Дефекты

BUG-01 · P1 · Подтверждение при пустом или некорректном телефоне

На шаге 3 указать имя Анна, очистить телефон и нажать «Подтвердить запись». Повторить с «абв!?». Фактически в обоих случаях показано сообщение об успешной записи. Ожидалась блокировка отправки и подсказка формата. Высокий приоритет: салон получает подтверждение визита без рабочего контакта.

BUG-02 · P2 · Форма принимает некорректное имя

Ввести корректный тестовый телефон, по очереди отправить форму с пустым именем, одной буквой Я, 41 буквой Я и именем Anna. Фактически каждый раз показано подтверждение. Ожидалась ошибка имени с сохранением остальных полей. Ошибка нарушает требования к идентификации клиента; при корректном телефоне связь всё ещё возможна.
