# ÉLAIRE — тест-дизайн контактной формы

## Классы эквивалентности и границы

Тестируем форму на шаге подтверждения, с выбранной услугой и временем. При проверке одного поля второе заполнено корректно. «Принять» означает разрешить подтверждение, «отклонить» — сохранить форму и указать поле для исправления.

| Поле / класс | Пример или граничный тест | Ожидание |
|---|---|---|
| Имя, пустое | пустая строка (0) | Отклонить |
| Имя, слишком короткое | Я (1) | Отклонить |
| Имя, нижняя граница | Ян (2), Ева (3) | Принять оба |
| Имя, верхняя граница | Строки из 39 и 40 букв Я | Принять обе |
| Имя, превышение длины | Строка из 41 буквы Я | Отклонить |
| Имя, кириллица с Ё | Алёна | Принять |
| Имя, латиница, цифра, дефис, пробел | Anna, Анна2, Анна-Мария, два пробела | Отклонить каждое отдельно по правилу «только буквы кириллицы» |
| Телефон, корректный | +7 (999) 000-00-01 — 11 цифр с кодом страны | Принять |
| Телефон, отсутствует | Пустая строка, затем одна лишь маска +7 | Отклонить оба |
| Телефон, нехватка одной цифры | +7 (999) 000-00-0 — 10 цифр | Отклонить |
| Телефон, лишняя цифра | Вставить +7 (999) 000-00-011 — 12 цифр | Отклонить лишний ввод либо всю вставку; не сохранять 12 цифр |
| Телефон, неверный код страны той же длины | +1 (999) 000-00-01 | Отклонить |
| Телефон, стационарный код | +7 (495) 000-00-01 | Отклонить по условию «мобильный» |
| Телефон, недопустимый символ | Заменить последнюю цифру на А или ! | Отклонить оба |
| Телефон, нарушена маска | Вставить +79990000001 | Разрешить только если поле приводит ввод к требуемому формату; иначе показать ошибку |

Для типа символа и кода страны числовых границ нет. Для изоляции этих классов меняем один символ в уже допустимом значении, сохраняя длину.

## Таблица решений

Проверяется правило подтверждения. В строках с заполненным именем оно валидно. Тесты неверного имени при непустом значении приведены выше. Пустой телефон не может одновременно быть валидным.

| Правило | Имя заполнено | Телефон заполнен | Телефон валиден | Результат |
|---|---|---|---|---|
| D1 | Да | Да | Да | Подтвердить |
| D2 | Да | Да | Нет | Ошибка формата телефона |
| D3 | Да | Нет | Да | Недостижимая комбинация |
| D4 | Да | Нет | Нет | Запросить телефон |
| D5 | Нет | Да | Да | Запросить имя |
| D6 | Нет | Да | Нет | Запросить имя и исправление телефона |
| D7 | Нет | Нет | Да | Недостижимая комбинация |
| D8 | Нет | Нет | Нет | Запросить оба поля |

В D2, D4, D5, D6 и D8 запись не должна появиться, а введённые данные должны остаться в форме.
